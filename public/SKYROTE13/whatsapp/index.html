Activar el envío de WhatsApp

La ficha de empresa prepara la imagen y el mensaje de Julio. El envío se realiza a través de su sesión existente en Sistema LR y una función privada de Supabase.

Falta activar Supabase. El nuevo paquete recibido confirma que la API de Sistema LR ya está publicada. Nexo utiliza ese mismo contrato. Todavía hay que instalar la función privada y sus secretos en tu proyecto de Supabase; este sitio no confirma una conexión real hasta comprobarla.

1. Revisar tu WhatsApp en Sistema LR

Abre Sistema LR → Campañas → Mi WhatsApp comercial. Vincula tu número +51 936 755 465 si figura desconectado. Nexo reutiliza esa sesión; no muestra otro QR ni necesita acceso al repositorio de LR. Según el informe entregado, la API ya está publicada; el último estado documentado del teléfono era desconectado.

La clave se configurará en los secretos de Supabase, nunca en el chat ni en el código público del sitio.

2. Instalar el registro de intentos en Supabase

Abre el SQL Editor de tu proyecto. Copia y ejecuta el SQL adicional completo. Añade una tabla de envíos sin borrar tus empresas, tareas, ventas ni cobros.

Descargar SQL adicional

Este es un cambio nuevo para WhatsApp; el pipeline de cinco etapas no necesitaba esta instalación.

3. Desplegar la función privada

Descarga y extrae el paquete. Desde su carpeta, con Node.js instalado, ejecuta:

npx supabase login
npx supabase functions deploy crm-whatsapp --project-ref hwilhpcermjxsaplando
Descargar función de Supabase

La función valida la sesión personal y la autorización del CRM en cada solicitud. El paquete no contiene contraseñas ni una clave LR.

4. Configurar los secretos del servidor

Abre Supabase → Edge Functions → Secrets y agrega:

LR_WHATSAPP_ENDPOINT = https://www.sistemalr.com/api/bot-action?externalWhatsApp=v1
LR_WHATSAPP_TOKEN = pega aquí la credencial privada que recibiste de LR
LR_WHATSAPP_ENABLED = false
NEXO_WHATSAPP_OWNER_ID = UUID de tu usuario personal del CRM

Copia el UUID desde Supabase → Authentication → Users, seleccionando tu cuenta del CRM. Vincula la conexión a esa cuenta, aunque después autorices a otras personas en el proyecto.

Las variables internas SUPABASE_URL, SUPABASE_ANON_KEY y SUPABASE_SERVICE_ROLE_KEY las proporciona el entorno de Edge Functions. No se copian a la landing ni a la configuración pública del CRM.

5. Comprobar sin enviar y activar

  1. Inicia sesión en Nexo y abre una empresa propia de prueba → Enviar WhatsApp.
  2. Selecciona un teléfono controlado por ti. Revisa el texto y la imagen, confirma el correo previo mencionado y registra la autorización que exige el contrato LR.
  3. Pulsa Comprobar conexión. Debe confirmar el WhatsApp de Julio para enviar de verdad. Si aún no lo vinculaste, puedes continuar con la validación sin envío.
  4. Pulsa Validar sin enviar. El resultado debe indicar validación correcta, sin mensaje real.
  5. Cuando la validación sea correcta y el WhatsApp esté conectado, cambia el secreto LR_WHATSAPP_ENABLED a true, comprueba de nuevo la conexión y realiza una prueba propia con Enviar imagen y mensaje.

Un resultado En cola aún no registra un contacto. Enviado a WhatsApp registra el canal y la hora en Nexo; no significa que el destinatario lo haya recibido o leído.

Si aparece Resultado por verificar, conserva ese intento. No crees otro para repetirlo. El botón de revisión recupera su estado usando el mismo identificador.
