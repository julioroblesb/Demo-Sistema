Actualizar el servidor de envíos.

El aviso de tu captura significa que Supabase aún tiene una versión anterior. Actualiza las dos funciones siguientes: sirve tanto para computadora como para celular. Tus claves de Zoho y WhatsApp se conservan; no cambies los secretos ni el DNS y no ejecutes SQL.

Las campañas se guardan en Supabase. Para procesarlas, mantén una sesión del CRM abierta. Puedes cerrar el formulario y preparar más campañas mientras esperan su turno.

Desde tu computadora Windows

Descarga el paquete, extrae todos los archivos y abre Actualizar-Nexo.cmd. Autoriza Supabase en el navegador; el instalador despliega ambas funciones. Necesitas Node.js LTS.

Después de desplegar las dos funciones

Vuelve al CRM, recarga la página y crea la campaña. Las empresas pasan de Filtrado a Contactado cuando el proveedor confirma su envío. Se guardan el canal, la fecha y la hora. Un mensaje pendiente o con error no cuenta como contacto; las empresas en Seguimiento o Ganado conservan su etapa.
